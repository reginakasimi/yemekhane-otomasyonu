--- 2. SERVİSLER ---

mysql-primary:
  Ana veritabanı. Yazma işlemleri buraya gider.
  Örnek: rezervasyon yapmak, bakiye yüklemek.

mysql-replica:
  Kopya veritabanı. Sadece okuma yapılır (salt okunur).
  Aynı zamanda yedek: kaynak bozulursa veri burada var.

replica-setup:
  Replikayı bir kez kurar, sonra kapanır.
  Exited (0) = başarılı. Bu normaldir.

redis:
  Çok hızlı hafıza.
  Menü önbelleği ve oturum (session) burada saklanır.

frontend:
  Apache web sunucusu. Adres: localhost:8080.
  HTML ve CSS dosyalarını gösterir.
  İstekleri uygulamaya gönderir.

uygulama:
  Benim yazacağım program. Port: 8000.
  Veritabanına sadece bu servis bağlanır.


--- 3. KELİMELER ---

container     = kutu içinde çalışan program
image (imaj)  = container'ın şablonu 
volume        = kalıcı depolama . Container silinse bile
                veri kalır.
healthcheck   = sağlık kontrolü. Servis çalışıyor mu? 
healthy       = sağlıklı, çalışıyor 
port          = kapı numarası 
ağ (network)  = container'ların birbirine bağlandığı yer 
replikasyon   = verinin başka sunucuya kopyalanması 
kaynak        = source, ana sunucu 
replika       = kopya sunucu 
GTID          = her işlemin tek numarası
                Replika hangi işlemi almadığını bilir ve onları alır.
salt okunur   = read-only. Sadece okunur, yazılamaz
önbellek      = cache. Hızlı erişim için geçici kopya 
oturum        = session. Giriş yapan kullanıcının bilgisi
migration     = veritabanı değişikliği dosyası
stored procedure (saklı yordam) = veritabanındaki hazır işlem
view (görünüm) = hazır sorgu, sanal tablo 
bakiye        = hesaptaki para 
rezervasyon   = yer ayırtma 
hata          = error 


--- 4. KOMUTLAR ---

docker compose up -d       = sistemi arka planda başlatır 
docker compose ps -a       = tüm servislerin durumunu gösterir
docker compose stop X      = X servisini durdurur
docker compose start X     = X servisini başlatır
docker compose logs X      = X servisinin günlüğünü gösterir 
docker compose down        = servisleri kapatır, veri KALIR
docker compose down -v     = servisleri kapatır, TÜM VERİ SİLİNİR!
